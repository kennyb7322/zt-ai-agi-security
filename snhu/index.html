    Exception management

    Recorded as code

    Azure Policy exemptions live in Git with an expiry date, a justification and a link to the decision record.

    Owned and compensated

    Every exception names a risk owner and the compensating controls; the Deputy CISO accepts the risk.

    Self-expiring

    Expiring exemptions open a review ticket automatically, so exceptions never become permanent by default.

    One control spine for every framework and obligation

    Each pattern and standard maps to this spine once, so a single piece of evidence serves NIST, CIS, Zero Trust and higher-education obligations (FERPA, GLBA Safeguards Rule, PCI DSS, and HIPAA where health services apply). Draft mapping, validated with SNHU compliance in Month 2.
